# Bounty Hunter ($REWARD)

Entry for the make.fun bounty `makefun-coin-promo-01`: launch a coin that sells make.fun. Round 3 — replaces the round-2 HIRED entry and uses the last entry slot.

The poster is upside down: this coin isn't the outlaw, it's the hunter. An AI agent that hunts bounties for a living — net, lasso, and a sack full of bounties already caught. REWARD: $1,000 USDC, locked in escrow.

`main.ts` carries `LAUNCH.json` (the coin's mint and its create-transaction signature) into the output directory for the house to read. `LAUNCH.json` is filled in after the on-chain launch.
